# Change Request

## Trigger phrases
- Prepare a change request
- I need to make an infrastructure change
- Help me plan a change
- Prepare the change plan
- Create an implementation plan
- Create a rollback plan
- Assess this infrastructure change
- What is the impact of this change
- Check the risk of this change

## Flow
1. Capture change description and reason.
2. Identify affected systems/services and expected impact.
3. Prepare implementation, validation and rollback details based on approved knowledge.
4. Identify maintenance window and owner.
5. Determine approval status using approved organizational criteria.
6. If production change is true and approval is not Approved, stop before execution and continue only with planning/information.
