# Installation Request

## Trigger phrases
- I need to install new equipment
- We need a new installation
- Plan an infrastructure installation
- Install equipment at the site
- We need a new printer installed
- Install a network device
- Prepare the site for installation
- Check installation requirements
- Help with site readiness
- Vendor is coming for installation

## Flow
1. Identify site and equipment.
2. Find approved installation guidance.
3. Check prerequisites and dependencies.
4. Check site readiness.
5. Separate internal and vendor actions.
6. Identify change/approval requirements.
7. Produce a concise installation checklist and next action.
