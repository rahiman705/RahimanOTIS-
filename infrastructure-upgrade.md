# Infrastructure Upgrade

## Trigger phrases
- We need to upgrade infrastructure
- Prepare an upgrade plan
- Plan the network upgrade
- Upgrade this device
- Prepare for infrastructure replacement
- Check upgrade requirements
- Create an upgrade checklist
- We need to replace old equipment

## Flow
1. Establish current state/version/configuration.
2. Establish target state/version/configuration.
3. Identify dependencies and affected services.
4. Determine business impact and maintenance/change window.
5. Identify backup, rollback, vendor and approval requirements.
6. Define validation steps.
7. Recommend the next safe action.
