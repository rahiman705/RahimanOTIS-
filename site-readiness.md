# Site Readiness

## Trigger phrases
- Is the site ready
- Check site readiness
- Prepare a site readiness checklist
- What do we need at the site
- Check prerequisites for this site
- Is everything ready for installation
- What is missing before installation
- Prepare the site for the upgrade
- Check infrastructure readiness

## Flow
Check relevant readiness items using VerificationStatus:
- Power
- Network
- Cabling
- Space
- Equipment delivery
- Access
- Vendor readiness

Never treat Not Verified as ready. Summarize verified items, gaps and the next action.
