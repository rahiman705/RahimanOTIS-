# Infrastructure Request Triage

## Trigger phrases
- I have an infrastructure request
- Help with this request
- Can you check this IT request
- What should we do with this request
- Review this infrastructure request
- Analyze this request
- What is the next action
- Who needs to take action
- Help me understand this issue
- What information are we missing

## Flow
1. Capture the original request and summary.
2. Classify RequestType.
3. Extract Country, Site, Service, System and Device when present.
4. Determine business impact and deadline when present.
5. Ask only for information necessary for classification or safe progression.
6. Route to the matching specialist topic while retaining shared context.

## Routing
- Incident -> Infrastructure Incident
- Installation -> Installation Request
- Upgrade -> Infrastructure Upgrade
- Change -> Change Request
- Vendor Coordination -> Vendor Coordination
- Site Readiness -> Site Readiness
- Documentation -> Find Infrastructure Documentation

If classification is uncertain, summarize what is understood and ask the minimum necessary question. Do not guess.
