# Infrastructure Incident

## Trigger phrases
- There is an infrastructure issue
- We have a network problem
- The site is down
- Users cannot connect
- Internet is not working
- Network is unavailable
- Server is unavailable
- We have an outage
- Infrastructure service is down
- Investigate this infrastructure incident
- Help troubleshoot this issue

## Flow
1. Identify site, service and symptoms.
2. Capture start time, affected users and business impact.
3. Capture error messages, recent changes and troubleshooting already performed.
4. Search approved knowledge.
5. Separate verified facts from possible causes.
6. Recommend investigation or escalation.
7. Do not declare root cause unless evidence supports it.
