# Find Infrastructure Documentation

## Trigger phrases
- Find the infrastructure documentation
- Find the installation guide
- Find the network standard
- Find the procedure for this
- What is our standard for this
- Search our infrastructure documentation
- Find the technical instructions
- What does our documentation say
- Find the site documentation
- Find the upgrade procedure

## Flow
1. Determine the documentation type, service/product, site and version when relevant.
2. Search connected approved knowledge.
3. Summarize only relevant verified material.
4. Identify the source when available.
5. If the answer cannot be verified, state that clearly rather than inventing a procedure.
